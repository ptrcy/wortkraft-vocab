# WortKraft — Vokabeln im Kontext lernen (Vocabulary Learning Tool)

A modern client-side web application for contextual vocabulary acquisition (starting with German B1/B2 level). The app pre-generates 10 contextual sentences, audio, and linguistic breakdowns per word, then trains you using weighted spaced repetition.

---

## 🌟 Key Features

### 1. Context-First Learning (Core Flow)
- **A-Res Weighted Sampling**: Selects $N$ random words (default: 5) weighted by your current mastery level.
- **2 Contextual Sentences per Word**: Picked dynamically from the word's 10 pre-generated sentences.
- **Crystal-Clear Audio**: Authentic, slightly slow German pronunciation powered by Gemini TTS and cached in IndexedDB (with Web Speech API fallback).
- **Cloze Mode (Lückentext)**: Hide/mask the target word in sentences to test your context inference skills.
- **Hidden Meanings & Grammar**: Meanings are hidden by default so you can guess from context first, then revealed on-demand.
- **Daily Spaced Repetition**: "Als gelernt markieren" increases `masteryLevel` by 1 (capped at once per calendar day).

### 2. Spaced Repetition (A-Res Algorithm)
- Mastery Level: $m \ge 0$
- Probability Weight: $w = \max(0.02, 0.4^m)$
- Selection Formula (Algorithm R with Exponential Jumps / A-Res without replacement):
  $$k_i = u_i^{1 / w_i} \quad \text{where } u_i \sim \text{Uniform}(0, 1)$$
- Words with lower mastery have higher weights and surface frequently, while mastered words decay in frequency down to a 2% floor for retention checks.

### 3. Dual Storage Architecture
- **`localStorage`**: Stores vocabulary metadata, 10-sentence text pools, grammatical breakdowns, memory hooks, mastery history, and app settings.
- **`IndexedDB` (`VTL_AudioDB`)**: Stores binary audio blobs generated by Gemini TTS to avoid localStorage size limits.

### 4. AI-Powered Pre-generation
- **OpenAI API**: Generates 10 B1-level contextual sentences, true part of speech (overriding casing heuristics), gender/articles, verb forms, governing prepositions (*Rektion*), and memory hooks (*Eselsbrücken*).
- **Gemini TTS API**: Synthesizes slow, distinct, authentic German audio for each sentence during word addition.

## 🚀 Quick Start

### Running Locally
```bash
# 1. Install dependencies
npm install

# 2. Start Vite development server
npm run dev

# 3. Open in your browser (typically http://localhost:5173)
```

### Keyboard Shortcuts
- <kbd>R</kbd> : Refresh session (Picks $N$ new words using A-Res)
- <kbd>M</kbd> : Toggle all meanings
- <kbd>1</kbd> – <kbd>5</kbd> : Toggle meaning for word #1 to #5
- <kbd>Space</kbd> : Stop/play audio
